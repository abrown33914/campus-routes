# Campus Routes (COT 3400)

Finds routes and tours on the FGCU campus map.

Run it:
    python src/main.py

## Files
- `src/main.py`: runs the program, asks questions, prints answers (R5, R6, R7)
- `src/loader.py`: reads the CSV, sorts and dedupes names, looks up names (R1, R2, R3)
- `src/graph.py`: builds the adjacency list (R4)
- `src/min_heap.py`: priority queue for Dijkstra (R8)
- `src/dijkstra.py`: shortest/fastest route and path (R5, R6)
- `src/tour.py`: brute force and nearest-neighbor tours (R7)
